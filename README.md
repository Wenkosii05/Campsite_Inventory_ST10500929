Campsite Inventory is a simple and interactive application that provides the campers a way of digitally packing
and having a way to overview everything from thier mobile without unpacking everything. The application is created 
using Kotlin in Android Studio. 

Features:
- Manually enter data
- Different categories to pack that are essential for camping
- Different buttons to show what is packed per category

How it works 
- User enters what is packed based on the selected category
- Up to 4 items may be added
- User will also update the quantity as they add to keep track of how many items are packed
- Once completed on one category, they click on next category and move to the next category
- Application will cycle through all of the categories and once complete the user will be alerted and can move to the next stage
- User can also skip to see what has been packed on the display screen.
